# Seller app (login, onboarding, Aujourd'hui, shell)

Mode: Operate. Task: each morning know who to follow up and do it; first session: reach a live test link in minutes. States: empty workspace, first link live, hot/warm/cold deals, overdue follow-ups, team view.

## Direction contract
THESIS: The working screen is a reading report: each deal a measured specimen with its heat reading and one next action. Refuses the grey KPI-card dashboard.
OWN-WORLD: Same thermography report world in Operate register: cool white paper (light) / graphite night (dark), hairline grid, numbered fields, achromatic chrome. Ironbow only on heat data (deal heat strip, page plates, scale). Hatch = overdue, nothing else. Tabular digits that cross-fade.
STORY: I open Clozer → the report header says who is hot today → I act on the first line → done.
FIRST VIEWPORT: Aujourd'hui: header line "Rapport du jour" with date and one sentence verdict; first row is the single next action (prospect, hottest page reading, Relancer button); below, the ranked list of deals as report rows with heat strips. Empty state: the onboarding sheet with numbered margin steps.
FORM: Rapport de thermographie, candidate 7 of 7, seed: none (unavailable)
Signature interaction: a deal row's heat strip refills when a live read arrives; reticle marks the hottest page.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
